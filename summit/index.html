Where an eight-store dealer group loses money, and how this system finds it

Explanations are on: every note is shown. Turn the switch off to hide them; each figure's i button still opens its own note.

Summit is a fictional dealer group built on synthetic data. The system reads its sales, service, inventory and funding records, flags the stores and records that need action, and puts them in work queues. This page sizes the problem honestly. It shows what is measured, what is only a forecast, and what would have to happen before anyone could call the benefit proven.

        5Tradeoffs I made

        • 4 assistant test cases contradict the approved document rules, so they are withheld and reported, not counted as passes.
        • The assistant answers only from current documents that list the reader's role and store, with no implied hierarchy. A row filter on the document table backs this up for everyone outside the admin group.
        • No figure is called incremental without a control group, even where the source data labels it "verified".
