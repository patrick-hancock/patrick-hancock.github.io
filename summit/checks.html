How it is measured

Detector rule
A target store is flagged when it ranks within the targets and sits more than 2 standard deviations from the other stores; when the other stores do not vary at all, it is flagged if it is above every one of them.
Not detected
SCN-INV-03 (high web views, no sale) is expected not to be detected: the engagement data is too sparse to test.

The Power BI model and its DAX check

The semantic model is a Power BI Project (PBIP, text files) generated from the same definitions as the SQL. A script opens it in Power BI Desktop, evaluates every measure through DAX for the group and each store, and compares the answers with the expected values. It ran 2026-11-18 at 13:39:06, tolerance 0.0001.
