3. Data quality checks

dbt runs these tests on every build; all 48 passed in the last run on 2026-10-13.

  • Unique, non-null keys Pass Every gold table's key is tested unique and not null.
  • Relationships Pass Every monthly fact row must join to a metro and a month in the dimensions.
  • HUD coverage Pass Every metro area must carry a HUD Fair Market Rent.
  • Match-rate floor Pass The build fails if fewer than 95% of Zillow metros match a Census area, or if any top-100 metro is unmatched.
