Rental Insights

A governed data and AI system on public US rental data

Role: Architect & Validator • Stack: BigQuery, dbt, Python, MCP • Status: Complete. The code is public on GitHub.

A tested pipeline loads public rental data (Zillow rent indexes, HUD Fair Market Rents and Census ACS) into BigQuery and models it in dbt from bronze to gold, with data-quality checks on every gold table. An MCP server answers questions with a citation or a refusal, behind read-only SQL guardrails and a 19-risk threat model. A 40-question golden set measures the answers (33 of 40 correct in a blind run), and every build task runs against a token budget with a hard cap.

3. Data quality checks

dbt runs these tests on every build; all 48 passed in the last run on 2026-10-13.

  • Unique, non-null keys Pass Every gold table's key is tested unique and not null.
  • Relationships Pass Every monthly fact row must join to a metro and a month in the dimensions.
  • HUD coverage Pass Every metro area must carry a HUD Fair Market Rent.
  • Match-rate floor Pass The build fails if fewer than 95% of Zillow metros match a Census area, or if any top-100 metro is unmatched.
