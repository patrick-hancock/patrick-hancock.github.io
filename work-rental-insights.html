How the data flows

dbt builds each layer, and tests run at every step before the next layer reads it.

  1. Sources Public rental data Zillow rent indexes, HUD Fair Market Rents and Census ACS
  2. Bronze Raw rows in BigQuery Loaded as published and counted against the source files
  3. Silver Typed and cleaned Zillow metros matched to Census areas by name, plus a seed of overrides
  4. Gold Two facts and two dimensions Key and relationship tests on every table
  5. MCP server Questions answered from gold Three tools return a cited source or a refusal

Data quality checks

dbt runs these tests on every build; all 48 passed in the last run on 2026-10-13.

  • Unique, non-null keys Every gold table's key is tested unique and not null. Pass
  • Relationships Every monthly fact row must join to a metro and a month in the dimensions. Pass
  • HUD coverage Every metro area must carry a HUD Fair Market Rent. Pass
  • Match-rate floor The build fails if fewer than 95% of Zillow metros match a Census area, or if any top-100 metro is unmatched. Pass
