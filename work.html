Data and AI system

Rental Insights

A governed data and AI system on public US rental data

A tested pipeline loads public rental data (Zillow rent indexes, HUD Fair Market Rents and Census ACS) into BigQuery and models it in dbt from bronze to gold, with data-quality checks on every gold table. An MCP server answers questions with a citation or a refusal, behind read-only SQL guardrails and a 19-risk threat model. A 40-question golden set measures the answers (33 of 40 correct in a blind run), and every build task runs against a token budget with a hard cap.

  • Data: dbt
  • Data: BigQuery
  • Data: Data quality checks
  • AI: MCP server
  • AI: SQL guardrails
  • AI: LLM evaluation

AI Control Testing

Security testing for an AI assistant, decided by evidence

A small case assistant for a fictional advisory firm, built with ten realistic flaws behind one switch each, plus the harness that attacks it. Each flaw has a vulnerable run, a one-commit fix and a replay that proves the fix. Results come from canary markers, tool-call traces and database side effects, never from an AI grader.

  • AI: Threat modeling
  • AI: MCP tools
  • AI: Prompt injection testing
  • Data: Python test harness

Grounded Q&A service

Domain Q&A Service

One question box over definitions, process documents and live data, with every answer cited or refused

A production question-answering service that replaced searching three separate places: a domain dictionary, process documents and the data warehouse. Every answer traces to a cited source, whether a dictionary entry, a document passage or an executed SQL statement, and when the evidence is weak the service says it has no data instead of guessing. Generated SQL passes a read-only guardrail and a personal-data block before it runs.

  • AI: Retrieval with citations
  • AI: Natural language to SQL
  • AI: SQL guardrails
  • Data: Hybrid search
  • Data: Data warehouse
