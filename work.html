Data and AI system

Rental Insights

A governed data and AI system on public US rental data

A tested pipeline loads public rental data (Zillow rent indexes, HUD Fair Market Rents and Census ACS) into BigQuery and models it in dbt from bronze to gold, with data-quality checks on every gold table. An MCP server answers questions with a citation or a refusal, behind read-only SQL guardrails and a 19-risk threat model. A 40-question golden set measures the answers (33 of 40 correct in a blind run), and every build task is tracked against a token budget.

AI knowledge assistant

Cite-or-Refuse Assistant

A production AI assistant that answers from a team's own sources, or says it cannot

Staff answering regulatory and process questions used to search three places: a domain dictionary, process documents and the data warehouse. I designed one question service that answers across all three, in a web page or inside a chat client, and treats every answer as a claim it must prove. A sentence without a source is rejected in code before anyone sees it, weak evidence returns "no data" instead of a guess, and generated SQL is checked before it runs. When someone flags a wrong answer, it is routed as a content correction or a software defect.

  • AI: Retrieval with citations
  • AI: Natural language to SQL
  • AI: SQL guardrails
  • AI: Answer feedback loop

AI Control Testing

Security testing for an AI assistant, decided by evidence

A small case assistant for a fictional advisory firm, built with ten realistic flaws behind one switch each, plus the harness that attacks it. Each flaw has a vulnerable run, a one-commit fix and a replay that proves the fix. Results come from canary markers, tool-call traces and database side effects, never from an AI grader.
